
# Student Registration Form

A simple and responsive Student Registration Form built using HTML, CSS, and JavaScript.  
This project allows users to enter student details and validates the form before submission.

---

## 📌 Features

- Responsive registration form UI
- Input fields for student details
- Form validation using JavaScript
- Success and error messages
- Attractive modern design with CSS

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
